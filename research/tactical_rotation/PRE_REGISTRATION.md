## 1. Design
Event study with static holdings (the frozen book is buy-and-hold, rebalance_every = 100), using the frozen A100 books of every Issue-#14 window (sets A and B) as the PIT frozen holdings on each date.
* **Signal / event (past data only):** broad sell-off day d = equal-weight-universe median return ≤ −2.0 %. Trade at d+1 VWAP (entry), measured to close of d+1+h, h ∈ {3, 5, 10, 24}. Events < 10 trading days apart are merged (first kept). DISCOVERY = entries < 2025-07-01; OOS = later; RECENT = entries ≥ 2026-07-01. An **unconditional control** (every 6th day) is run to see whether any effect is state dependent.
* **Rotation:** sell the TECH cluster pro rata (TECH = same 7 TWSE industries as Issue #41) by x % NAV, buy the sleeve. Sizes x ∈ {10, 20, 30, 40} % (+ x* if the feasible limit binds first).
* **Structures (all in-universe, non-TECH):** T1 2412 only; T2 liquid non-TECH basket excluding 2412 (6 names with the highest 20-day traded value, equal weight within caps); T3 2412 + basket; T4 six lowest-60d-volatility liquid non-TECH names; T5 six most liquid financials; T6 placebo: 6 random non-TECH names (20 seeds); T7 raise cash only (up to the cash < 25 % limit); control = frozen holdings. Benchmarks: EW universe, EW TECH, EW semiconductors, random compliant portfolios (500 random 20–30-name equal-weight portfolios; rank percentile).
* **Execution model:** official costs (fee 0.1425 % each way, tax 0.3 % on sells), 0.25 % rebalance threshold, no market impact in the official simulator (reported separately); real-market participation = trade value / 20-day average daily traded value.
* **Re-entry rule R (fixed now):** after rotating at entry e, hold the sleeve for ≥ 3 days; re-enter TECH when on 2 consecutive closes (a) TECH breadth (share of TECH names above their 20-day MA) > 0.50 AND (b) TECH equal-weight 5-day return − universe equal-weight 5-day return > 0. Re-entry is staged 50 % on the first confirmation day and 50 % the next; time stop = day 10. Compared with never re-entering within 24 days and with the frozen control.

## 2. Primary test and gate
Primary: T3 at x ∈ {20, 30, 40} %, h ∈ {5, 10}, **OOS events**: mean excess return vs frozen (Δ) and its sign-flip permutation p (events as units). 6 tests, Holm-adjusted.
Gate to recommend ROTATE_*: all of (G1) Δ > 0 in DISCOVERY and OOS for both h, (G2) Holm p < 0.10 in OOS, (G3) beats T6 placebo and T7 cash-only, (G4) hit rate ≥ 55 %, (G5) not driven by one episode (leave-one-episode-out sign unchanged), (G6) RECENT slice same sign, (G7) no rule violation, Active Share ≥ 15 % (we require ≥ 25 % margin), participation ≤ 5 % of ADV, (G8) re-entry rule R does not make the result worse than holding.
Otherwise DO_NOT_ROTATE (or SHADOW_ONLY if only the descriptive/live-post-hoc evidence is favourable). The live days 11/05–11/06 (and the market's reaction) are never used to select anything. Negative and null results are kept.
