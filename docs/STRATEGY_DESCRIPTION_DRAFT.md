## B. 技術附錄（內部 / 若主辦方要求補充說明時使用）

**定位：Hybrid Quant + LLM Agent**

```
公開資料（TWSE / TPEx / MOPS / ETF 發行商 / TAIFEX / 美股）
  → Quant Core v1（決定性：評分、選股、權重、現金、委託）        ← 決定投資組合
  → Facts / Evidence Graph（程式寫入的事實與來源）
  → Claude Code CLI（NARRATIVE_LOCKED）：市場觀點、持股論述、反方證據、MOPS 公告研究解讀
  → Grounding / Validation（Python 決定性）：引用 ID、數字、ticker、禁止指令、與決策一致性
  → D-Plan v4.2（合規檢查、fallback）→ FINAL（sha256 凍結）→ 人工上傳 → 稽核
```

| 元件 | 負責 | 不負責 |
|---|---|---|
| Quant Core v1（`config/strategy_quant_v1.yaml`，凍結） | 月營收 YoY 0.7 / MoM 0.3 百分位評分；目標 25 檔（24–27）分級權重；2330 ≤ 23.5%、其他 ≤ 9%；依市場廣度設定現金區間（官方 < 25% 不觸碰）；Active Share 目標 30%（官方 20%）；建倉後持有、僅在不合規 / 失格時交易 | 文字 |
| Claude Code CLI | 研究解讀（MOPS 重大訊息分類、正反證據、不確定性）、市場觀點、thesis、counter-evidence | 選股、權重、委託、現金、Active Share、regime |
| Python 決定性層 | 合規檢查、grounding、D-Plan 驗證、委託股數、fallback、FINAL、稽核 | — |
| Template | Claude 失敗時的永久 fallback 敘事 | — |

- **Claude 不決定投資組合**；Claude 的輸出在證據圖中只能是 Inference，引用程式寫入的公告事實，且只能附加到量化程式已產生的決策。
- **不誇大 LLM 對績效的影響**：決策與 Template 路徑完全相同（決策指紋一致），LLM 提升的是可解釋性與研究說明，不是報酬。
  Quant Core v1 相對隨機 25 檔組合的優勢小（中位數 +0.40%、5 窗中 3 窗），統計上無法與 0 區分（Round 03 報告 §16）。
- **合規**：每日 D-Plan 經 v4.2 驗證（張數整數、權重上限、現金、Active Share、時間窗）；失敗自動維持前日組合。
- **自主性**：資料抓取 → 決策 → 敘事 → 驗證 → FINAL 全部由 Agent 自動完成；人工只做「官方結算抄錄」與「上傳」，無人工投資判斷或文字修改（見 `docs/AGENT_AUTONOMY_EVIDENCE.md`）。
- **使用工具**：Claude Code CLI 以公司授權的組織管理 Team 帳號執行（AUTHORIZED_FOR_COMPETITION_USE）；主辦方規則未禁止外部 LLM，但未特別點名 Claude Code CLI。
